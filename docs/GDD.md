# 쿠킹 시뮬레이터 — 게임 기획서 (기획)

> 러프 아이디어: "스테이크를 손질부터 굽기, 플레이팅까지. 터치·흔들기·튕기기로 진짜 요리하듯."
> 이 문서는 그 아이디어를 **플레이 가능한 규칙**으로 다듬고, 각 요소가 왜 재미있는지 검증한 결과다.

## 1. 한 줄 콘셉트
**손이 기억하는 요리.** 정답 버튼을 누르는 게임이 아니라, 칼질·흔들기·팬 튕기기의 *손맛*과 *타이밍*이 그대로 맛이 되는 스테이크 시뮬레이터.

## 2. 핵심 재미 (Core Fun)와 검증
| 재미 축 | 설계 | 검증 포인트 |
|---|---|---|
| **촉각적 조작** | 드래그 궤적 = 칼날 궤적, 흔들기 세기 = 양념량, 플릭 세기 = 뒤집기 결과 | 입력 → 결과가 즉시·연속적으로 보인다 (근막이 벗겨지는 파티클, 양배추가 벌어짐, 알갱이가 떨어짐) |
| **타이밍 압박** | 전체 제한 시간 + 굽는 동안 실시간으로 진행되는 열 시뮬레이션 | 굽기 단계에서 "지금 뒤집을까? 지금 꺼낼까?"의 긴장 |
| **결과 공개의 쾌감** | 손님이 스테이크를 **써는 순간 단면 공개** (핑크빛 미디엄 레어 vs 회색) | 결과 화면에서 단면 애니메이션 → 점수 → 코멘트 순으로 공개 |
| **창작** | 자유 배치 플레이팅, 소스 그리기 | 같은 요리도 매번 다른 접시 → 스크린샷 욕구 |
| **숙련 곡선** | 플릭 세기 게이지, 잔열(꺼낸 후 +5~8℃) 학습, 손님별 까다로움 | 2~3회 플레이로 체감되는 성장 (QA 기록 참조) |

### 러프 아이디어에서 다듬은 점
1. **"고기를 돌려가며 근막만 자르기"를 실제 규칙으로**: 칼은 *가로 방향(±58°)* 으로만 들어간다. 근막 3개가 각기 다른 방향(가로/세로/곡선)에 있어 **고기를 돌려야만** 깔끔히 자를 수 있다. 근막을 벗어나면 살코기에 칼자국이 남고 손상으로 감점.
2. **흔들기 세기 = 양**: 중력 제외 가속도가 임계값(5m/s²)을 넘는 만큼 알갱이를 뿌린다. 세게 흔들면 많이·넓게 퍼지고, 약하게 흔들면 조금씩 정밀하게. 화면 드래그로 양념통 위치를 조준해 *고르게* 뿌려야 한다(고르기도 평가).
3. **뒤집기 세기 3구간**: 약함(<13) → 뒤집히다 **접힘**, 적정(13~26, 16~22는 '완벽한 플립') → 성공, 셈(>26) → 1.5바퀴 돌고 **접혀 떨어짐**. 접히면 탭으로 펴야 하고 그동안 고르게 익지 않는다. 매 플릭마다 세기 게이지를 보여줘 손이 학습하게 했다.
4. **"잘 익었는지"를 숫자 대신 눈으로**: 팬 위 고기의 *옆면*에 아래에서부터 익어 올라오는 색 띠, 중심 온도가 오르면 윗면에 맺히는 육즙 방울, 아랫면이 타면 연기. 온도계는 3번만.
5. **잔열 조리**: 꺼낸 뒤 90초(실제 시간) 레스팅을 시뮬레이션해 최종 굽기를 정한다. "목표보다 조금 일찍 꺼낸다"는 진짜 요리 지식이 곧 공략.
6. **양배추**는 자유 곡선 그대로 잘리는 "채썰기" 미니게임 → 결과물이 플레이팅의 *양배추 샐러드* 재료가 된다(안 올리면 감점). 단계 간 연결로 의미 부여.

## 3. 게임 흐름
```
타이틀(손님 선택) → 주문 → [제한시간 시작]
 1 근막 손질 → 2 양배추 채썰기 → 3 시즈닝(소금·후추·오일) → 4 굽기 → 5 플레이팅
 → 결과(손님이 썰기 → 단면 공개 → 시식 → 평가)
```
- 각 단계 시작 시 안내 카드가 뜨며, **읽는 동안은 타이머가 멈춘다**(읽기 페널티 없음).
- 굽기 이전에 시간이 다 되면 손님이 떠난다(최대 10점). 플레이팅 중이면 그 상태로 서빙.

## 4. 단계별 상세 규칙
### 1) 근막 손질
- 입력: 한 손가락 드래그 = 칼. 두 손가락 비틀기 또는 ⟲⟳ 버튼 = 고기 회전.
- 판정: 칼 궤적의 각 지점이 근막 중심선 ±0.62×폭 이내 → 근막 제거. 근막 밖 살코기 → 손상(mm). 지방층은 손상 없음.
- 97% 이상 제거 시 자동 완료.

### 2) 양배추 채썰기
- 드래그 궤적이 조각을 **밖→안→밖으로 관통**하면 그 궤적대로 분할(곡선 OK). 한 번의 획으로 여러 조각을 동시에.
- 가늘기 = 면적 가중 평균(조각 최소폭 7mm 이하 = 100%, 28mm 이상 = 0%).

### 3) 시즈닝
- 목표: 소금 2.4g × 손님 선호도, 후추 0.8g, 올리브오일 10ml. 고기 위에 떨어진 것만 계산.
- 첫 손님(튜토리얼)은 게이지에 적정 구간 표시. 이후 손님은 숨김.

### 4) 굽기
- 1차원 열전도 유한차분(15노드, 두께 28mm, 실제 물성치) × **9배속**. 팬 온도: 약 150 / 중 205 / 강 255℃로 수렴, 고기를 올리면 떨어짐.
- 마이야르 갈변도: 팬 온도 135℃ 이상에서 진행. 0.85~1.35 = 노릇노릇(만점), 1.75 초과 = 탐.
- 전략 예: 강불로 겉을 빠르게 지진 뒤 중불로 내려 속을 익히고, 자주 뒤집어 고르게.

### 5) 플레이팅
- 쟁반 2줄: 양배추 샐러드, 방울토마토, 아스파라거스, 로즈마리, 구운 마늘, 양송이, 허브 버터, 새싹, 플레이크 소금, 소스 붓.
- 스테이크: 슬라이스(부채꼴, 단면 공개) / 통째로 선택.
- 평가: 스테이크 위치, 재료 종류(3~5종 최적), 개수(4~14), 테두리 침범, 무게중심 균형, 소스 유무, 홀수 배치 보너스.

## 5. 평가 공식 (100점)
| 항목 | 배점 | 기준 |
|---|---|---|
| 손질 | 15 | 근막 제거율 × (1 − 손상 패널티, 최대 60%) |
| 채썰기 | 10 | 가늘기 × (샐러드 미사용 시 ×0.5) |
| 간 | 20 | 소금 11(로그 비율 정규분포), 후추 4, 오일 2, 고르기 3 |
| 굽기 | 37 | 중심온도 20(목표 ±3.4℃/까다로움), 크러스트 10, 양면 균일 3, 뒤집기 기술 4 |
| 플레이팅 | 13 | 위 규칙 |
| 시간 | 5 | 남은 시간 25% 이상이면 만점 |

**치명적 실수 상한**: 날것(목표 −9℃↓) 58점, 과조리(+9℃↑) 62점, 소금 2배↑ 62점, 탐 70점. → "다른 걸 다 잘해도 스테이크가 날것이면 4성은 없다"는 직관과 일치.
별: 90↑ ★5 / 75↑ ★4 / 60↑ ★3 / 40↑ ★2.

## 6. 손님(레벨)
| 손님 | 주문 | 시간 | 특징 |
|---|---|---|---|
| 김민준 | 미디엄 레어 | 5:00 | 튜토리얼: 적정 구간·힌트 표시 |
| 이서연 | 미디엄 | 4:30 | 짠맛 선호(소금 ×1.35), 힌트 없음, 까다로움 1.15 |
| 미식 평론가 B | 레어 | 3:50 | 소금 절제(×0.9), 까다로움 1.4 (허용 오차 대폭 축소) |
이전 손님에게 60점 이상이면 다음 손님 해금. 최고 점수 저장.

## 7. 재미 검증 결과 요약
- **자동 플레이 시뮬레이션**(tools/qa-playthrough.mjs)으로 "숙련된 플레이"와 "대충 플레이" 모두 끝까지 진행 가능함을 확인. 숙련 플레이 88점(★4), 대충 플레이는 낮은 점수 → **실력 차가 점수에 반영**.
- 굽기 밸런스(단위 테스트로 고정): 중불+자주 뒤집기 → 게임 시간 약 50초에 미디엄 레어, 크러스트 적정. 강불만 → 탐. 약불만 → 허연 겉면. → **불 조절이 의미 있는 선택**.
- 첫 플립을 일부러 약하게 하면 접힘 → 탭으로 펴기 → 재시도 흐름이 자연스럽게 이어짐(실패가 즉시 회복 가능해 좌절감이 적음).
- 자세한 내용은 [QA 보고서](QA.md).

## 8. 가게 경영 모드 (지속 플레이)
> 요청: "만족도가 쌓일수록 단가를 올릴 수 있게. 단가가 너무 높으면 만족도가 떨어지게. 요리대회로 손님 몰이. 가게가 커질수록 요리·단가 증가."

### 하루 흐름
```
가게(허브) → [영업 시작] 오늘의 대표 요리 선택 → 대표 손님 주문 → 5단계 요리 → 평가
          → 정산: 오늘 온 손님 전원이 이 요리로 가게를 평가 (만족도·방문객·매출·평판)
          ↘ [메뉴판] 요리별 단가 조절   ↘ [요리대회] 3일에 한 번   ↘ [가게 확장]
```
한 접시를 요리하면 그날 영업 전체가 정산되므로, 손님 수십 명을 일일이 요리하지 않아도 가게가 성장한다(1일 ≈ 3~4분).

### 핵심 공식 (`www/js/economy.js`)
| 항목 | 공식 | 의미 |
|---|---|---|
| 적정가 | 기본가 × (0.7 + 0.6×평판/100) × 가게 단계 배율 | **평판(누적 만족도)이 오를수록 받을 수 있는 단가가 오른다** |
| 고객 만족도 | 요리 점수 + 가격 효과. 적정가보다 비싸면 초과 비율×120 감점(10% 비싸면 −12), 싸면 최대 +8 | **단가가 너무 높으면 맛있어도 만족도 급락** |
| 방문객 | 가게 기본 손님 × (0.4+평판/100) × 대회 명성 × 가격 탄력성 | 싸면 손님이 조금 늘지만(포화, 최대 ×1.3), 비싸면 급감(가격비^−2.5) |
| 이익 | 방문객 × 단가 × (1+팁) − 방문객 × 기본가×35% | 만족도 90↑ 팁 10%, 80↑ 5% |
| 평판 | 평판 + (만족도 − 평판)×0.25 | 지수 이동 평균: 하루 실수는 회복 가능, 꾸준함이 보상 |

**밸런스 검증** (평판 70, 85점 요리 기준 하루 이익): 적정가 ×0.7 → 49만, ×0.85 → 56만, **×1.0 → 65만(최대)**, ×1.1 → 56만, ×1.4 → 42만.
→ 이익은 적정가 근처에서 최대. 싸게 팔면 평판은 빨리 오르지만 이익이 줄고, 폭리를 취하면 평판이 떨어져 확장이 막힌다. 메뉴판은 가격별 손님 반응(🤑/🙂/😟/😡), 만족도 증감, 예상 손님 수를 보여줘 감으로 조절하게 한다(정확한 적정가는 숨김).

### 가게 단계와 요리
| 단계 | 확장 조건 | 기본 손님 | 단가 배율 | 해금 요리 (기본가) | 요리 특성 |
|---|---|---|---|---|---|
| 1 골목 포장마차 | — | 40 | ×1.0 | 채끝 (₩18,000) | 기본 |
| 2 동네 비스트로 | ₩250만, 평판 65 | 70 | ×1.15 | 안심 (₩32,000) | 두께 38mm로 속 익히기 어려움, 근막 4개 |
| 3 스테이크 하우스 | ₩1,000만, 평판 75, **시 대회 입상** | 110 | ×1.3 | 꽃등심 (₩45,000) | 마블링 2.2배, 소금 기준 ×1.1 |
| 4 파인다이닝 | ₩3,200만, 평판 85, **전국 대회 입상** | 160 | ×1.5 | A5 와규 (₩120,000) | 두께 22mm로 몇 초 차이 승부, 마블링 4배, 소금 ×0.7 |
- 단계가 오를수록 손님이 까다로워지고(엄격도 +0.12/단계) 제한 시간이 줄어든다.
- 시뮬레이션(매일 88점, 적정가+5%): 4일차 비스트로, 7일차 스테이크 하우스, 9~12일차 파인다이닝. 평범한 75점 플레이는 대회 입상 전까지 2단계에 머문다 → 대회가 성장의 관문.

### 요리대회 (특별 이벤트)
| 대회 | 참가 단계 | 참가비 | 상금 (1/2/3위) | 명성 (5일간 손님 배율) | 과제 | 심사 엄격도 |
|---|---|---|---|---|---|---|
| 동네 요리대회 | 1 | 10만 | 100만 / 50만 / 20만 | ×1.5 / 1.3 / 1.15 | 채끝 | 1.3 |
| 시 요리대회 | 2 | 50만 | 600만 / 300만 / 100만 | ×1.6 / 1.35 / 1.15 | 안심 | 1.45 |
| 전국 챔피언십 | 3 | 200만 | 2,500만 / 1,200만 / 400만 | ×1.8 / 1.45 / 1.2 | 꽃등심 | 1.6 |
| 월드 그릴 마스터즈 | 4 | 1,000만 | 1.2억 / 5,000만 / 1,500만 | ×2.0 / 1.6 / 1.25 | 와규 | 1.8 |
- 경쟁자 5명의 점수(대회별 평균±편차)와 순위를 겨룬다. 3위 안이면 메달 + 상금 + **명성 버프(손님 증가)** + 평판 상승, 탈락하면 참가비 손실과 평판 −1.
- 대회는 3일에 한 번, 대회 날은 가게가 쉰다(영업 수익 포기) → 리스크와 보상의 선택.
- 힌트 없음, 짧은 제한 시간, 엄격한 심사 → 손님 영업보다 긴장감이 큰 챌린지.

### 재미 검증 포인트
- **장기 목표**: 다음 확장 조건이 항상 보이고(체크리스트), 확장하면 새 요리·새 대회가 열린다.
- **의미 있는 선택**: 가격(이익 vs 평판), 대회 참가(휴업·참가비 vs 상금·명성), 대표 요리 선택(쉬운 싼 요리 vs 어려운 비싼 요리).
- **실패의 회복성**: 평판은 이동 평균이라 한 번 망쳐도 며칠이면 회복.

## 9. v2 — 타이쿤 전환, 실제 레시피, 손질 재고, 앱 흐름
> 요청: "손님이 오면 즉시 조리하는 타이쿤식으로. 돈이 모이면 직원을 고용해 어느 정도 자동화하되 나도 직접 해야 하게." / "처음 실행하면 로고, Game Start, 프롤로그, 도움말." / "레시피는 실제 레시피를 따르고, 가니쉬는 내가 준비하는 만큼만." / "랍스타·새우·파스타 등 양식 메뉴 확대."

### 앱 흐름
`스플래시(STUDIO COOKS)` → `타이틀(GAME START · 도움말 · 설정)` → 첫 실행만 `프롤로그 5장` → `도움말 5장` → `가게(아침)`
- 설정: 사운드/진동 켜기·끄기, 도움말·프롤로그 다시 보기, 데이터 초기화
- 일시정지(⏸, 안드로이드 뒤로가기, 앱 백그라운드 전환 시 자동): 계속하기 / 도움말 / 설정 / 주문 포기 / 영업 중단
- 단계 안내 카드는 처음 한 번만, 이후엔 바로 조리 (숙련자 템포)

### 하루 루프 (실시간 타이쿤)
```
아침(가게): 준비대 손질 · 직원 · 메뉴판 · 대회 · 확장
   ↓ 영업 시작 (11:00~21:00 = 실제 5분)
홀: 손님 도착 → 착석 → 주문표(인내심 막대)
   ├ 🔪 직접 조리 → 레시피 단계 미니게임 (가게 시간은 계속 흐름, 손님 인내심 0.6배로 감소)
   ├ 👨‍🍳 직원이 안 맡긴 일반 주문을 자동 조리 (VIP 불가, 재료 없으면 불가)
   └ 🔪 준비대: 영업 중에도 손질 가능 (그동안에도 시간 흐름)
   ↓ 마감 → 정산: 매출 − 재료비 − 인건비, 평판 = 평균 만족도(놓친 손님 0점, VIP 2배) 쪽으로 이동, 남은 재료 절반 폐기
```
- **긴장감**: 요리하는 동안 다른 손님 인내심이 줄어든다 → 무엇을 내가 하고 무엇을 직원에게 맡길지, 언제 준비대에 갈지 판단.
- **직원 밸런스**: 견습(솜씨 66, 70초) / 숙련(76, 55초, 2단계) / 수셰프(85, 45초, 3단계). 사장 플레이(80~95점)보다 품질이 낮고 VIP·평론가는 사장만 → 자동화하되 핵심은 직접.
- 시뮬레이션: 혼자 운영하면 하루 손님 절반 이상을 놓쳐 1단계에 정체, 직원을 고용·교체하며 운영하면 약 18일 만에 파인다이닝.

### 실제 레시피 (10종)
| 단계 | 요리 | 실제 조리 순서 (게임 단계) |
|---|---|---|
| 1 | 채끝 스테이크 | 근막 손질 → 소금·후추·오일 → 팬 시어링(뒤집기, 잔열) → 플레이팅 |
| 1 | 알리오 올리오 | 소금물에 면(알 덴테 = 포장 시간 −1분, 면수 확보) → 오일+편마늘 약불 → 페페론치노 → 면+면수 → 팬 토스 유화 → 파슬리 |
| 1 | 감바스 알 아히요 | 새우 내장 제거 → 소금 → 넉넉한 오일+마늘 약불 → 페페론치노 → 새우 → 뒤집기 → 파슬리, 바게트 곁들임 |
| 2 | 안심 스테이크 | 스테이크와 동일 (두께 38mm, 근막 4개) |
| 2 | 까르보나라 (로마식) | 면 삶기 → 노른자+페코리노+후추 소스 → 관찰레 기름 내기(오일 없이) → 면+면수 → **불 끄기** → 소스 → 버무리기 (팬이 75℃ 넘으면 스크램블 실패, 크림 없음) |
| 2 | 새우 토마토 파스타 | 새우 손질 → 면 → 오일+마늘 → 새우 → 방울토마토 → 면+면수 → 토스 → 파슬리 |
| 3 | 꽃등심 스테이크 | 스테이크 (마블링 2.2배, 빨리 탐) |
| 3 | 랍스터 버터구이 | 꼬리 반 가르기 → 소금·후추 → 시어링 → 버터+마늘 → 버터 베이스팅 → 레몬 곁들임 |
| 4 | A5 와규 | 스테이크 (22mm, 마블링 4배, 소금 0.7배) |
| 4 | 랍스터 테르미도르 | 랍스터 데치기(4분) → 반 갈라 살 발라내기 → 버터·샬롯·화이트와인·크림·디종 소스에 살 버무림 → 치즈 올려 브로일 → 플레이팅 |

평가는 레시피의 단계별 점수(손질·간·굽기·삶기·소스·팬 요리·오븐·플레이팅)를 배점 정규화해 100점 만점으로 합산. 치명적 실수 상한 유지(날것 58, 면 덜 익음 65, 마늘 탐 66, 계란 스크램블 55 등).

### 손질 재고 (가니쉬는 '준비한 만큼만')
준비대 손질 11종: 양배추 채·마늘 슬라이스·방울토마토 반쪽·다진 파슬리·바게트·레몬 웨지·아스파라거스·양송이·다진 샬롯·관찰레·로즈마리.
- 모두 **같은 자유 곡선 칼질**로 손질하고, 결과물의 형태로 인분을 판정 (예: 마늘은 3.5mm 이하 슬라이스 6장 = 1인분, 토마토는 원래 크기의 35~65% 조각만 '반쪽', 아스파라거스는 밑동 20%만 잘라낸 대만 인정).
- 레시피 재료(마늘·파슬리·관찰레…)는 주문을 시작할 때 소모, 가니쉬는 플레이팅 때 놓은 만큼 소모. 접시 밖으로 빼면 쟁반으로 반환.
- 재료가 없으면 사장도 직원도 그 메뉴를 못 만든다 → 주문표에 "재료 부족" 표시. 마감 시 남은 재료의 절반은 폐기(신선도).

### 요리대회 과제
동네(채끝) → 시(까르보나라) → 전국(랍스터 버터구이) → 월드(A5 와규). 과제에 필요한 손질 재료를 가게 재고에서 가져가야 참가 가능.

## 난이도
설정 → 난이도에서 **쉬움(기본)·보통·어려움**을 고른다 (`www/js/difficulty.js`). 어려움이 원래 밸런스.

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 손님 인내심(주문 시간) | ×2.0 | ×1.4 | ×1 |
| 사장이 조리 중인 손님 인내심 감소 | ×0.15 (거의 안 줄어듦) | ×0.35 | ×0.6 |
| 다른 대기 손님 인내심 감소 | ×0.6 | ×0.85 | ×1 |
| 채점 허용 오차(깐깐함) | ×0.45 | ×0.7 | ×1 |
| 단계 점수 보정 | 부족분 50% 메움 | 25% | 없음 |
| 뒤집기 | 아무 세기나 성공(안 접힘) | 넓은 범위 | 원래 |
| 손질 칼 판정 | 넓고 손상 적음, 각도 제한 없음 | 조금 넓음 | 원래 |
| 겉면 타는 속도(노릇한 뒤) | ×0.65 | ×0.85 | ×1 |
| 도우미 | 속 온도 게이지·꺼낼 타이밍, 면 건질 타이밍, 계량 목표 구간, 자동 플레이팅 | 동일 | 온도계 3회 |
| 놓친 손님·평판 하락 | 영향 30%·하락 40% | 70%·75% | 100% |
| 하루 손님 수 | ×0.75 | ×0.9 | ×1 |

시뮬레이션(요리 1개 75초·68점 수준 플레이어, 1단계 가게): 어려움은 하루 손님 약 3명 놓치고 평판 −4, 쉬움은 거의 안 놓치고 평판 +5.
