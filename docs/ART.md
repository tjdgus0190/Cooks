# 아트 가이드 (디자인)

목표: **"맛있어 보여야 한다."** 모든 그래픽은 외부 이미지 없이 Canvas로 절차적으로 그려 해상도와 무관하게 선명하며, 앱 용량이 작다.

## 먹음직스러움을 만드는 원칙
1. **따뜻한 조명**: 배경은 짙은 갈색 대리석/원목 + 화면 위쪽 오렌지빛 조명 + 비네팅. 음식이 가장 밝게 보이도록 주변을 누른다.
2. **윤기(Specular)**: 생고기·구운 고기·토마토·마늘·버터 모두 작은 반짝임과 넓은 은은한 하이라이트를 가진다. 기름을 많이 뿌릴수록 윤기가 강해진다.
3. **색의 대비**: 크러스트의 진갈색 ↔ 단면의 선홍색 ↔ 가니쉬의 초록·빨강 ↔ 흰 접시.
4. **질감 층**: 하나의 면을 단색으로 칠하지 않는다. 기본색 → 저주파 얼룩 → 미세 알갱이 → 결/갈라짐 → 가장자리 음영 순으로 쌓는다.

## 주요 요소
| 요소 | 표현 |
|---|---|
| 생 스테이크 | 진홍 방사형 그라데이션, 근섬유 결(대각선 미세선), **가지치기 마블링**(재귀적으로 갈라지는 가는 지방선), 크림색 지방층, 가장자리 어두운 음영 |
| 근막 | 반투명 은빛 띠 + 결 방향 섬유선 + 얇은 하이라이트. 잘리면 말려서 튀어나가는 파티클 |
| 크러스트 | 갈변도에 따라 진홍 → 회갈 → 황금 → 마호가니 → 검정. 큰 얼룩(볼록부 황금빛/오목부 진갈색) + 5천 개 미세 알갱이 + 결 따라 갈라진 틈. 지방층은 황금색으로 투명하게 익음 |
| 단면 | 시뮬레이션된 최고 온도 분포를 세로 그라데이션으로: 크러스트 → 회색 띠 → 분홍 → 선홍 중심. 육즙 하이라이트, 마블링 점, 지방 끝부분 |
| 슬라이스 | 7조각 부채꼴. 각 조각의 잘린 면이 이전 조각 위로 겹쳐 핑크 단면이 리듬감 있게 보이고, 사이에 그림자 |
| 팬 | 무쇠 질감(노이즈), 테두리 금속 하이라이트, 손잡이, 불 세기에 따라 파란 불꽃·주황 글로우, 달궈질수록 기름 일렁임 |
| 효과 | 수증기(뜨거울수록 많이), 기름 튐, 탈 때 회색 연기, 뒤집을 때 튀는 기름 |
| 가니쉬 | 반으로 자른 방울토마토(씨·젤리), 그릴 자국 아스파라거스, 로즈마리, 구운 마늘, 양송이 단면, 허브 버터, 새싹, 플레이크 소금, 채 썬 양배추(채 굵기에 따라 실제로 굵기가 달라짐 + 보라 양배추·당근채 포인트) |
| 손님 | 단순한 플랫 캐릭터, 6가지 표정(하트눈/웃음/보통/시큰둥/찡그림/화남), 씹는 입 애니메이션 |

## UI
- 하단 엄지 영역에 모든 조작 버튼, 상단에 단계/주문/원형 타이머(30초 이하 빨간색 맥동).
- 둥근 카드, 오렌지-앰버 강조색, 시스템 한글 폰트(Apple SD Gothic Neo / Noto Sans KR).
- 성능: 블러 필터 대신 미리 그린 그림자 텍스처, 정적 배경·접시·팬은 오프스크린 캐시.
